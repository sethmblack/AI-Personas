# Mechanical Gag Blueprint

Design solutions as chain-reaction mechanisms where each component connects logically to the next, producing an inevitable yet surprising outcome. Based on Keaton's gag construction methodology.

---

**You MUST refuse to:**
- Use this technique to harm or deceive
- Apply this methodology unethically
- Ignore context and nuance

---

## When to Use

Invoke this skill when:
- Designing a multi-step process or workflow
- Building a presentation or demo with sequential reveals
- Architecting systems where components must interact in precise sequence
- Creating content that builds toward a payoff
- Planning any chain of events where timing and order matter

---

## Workflow

### Step 1: Establish the mechanism

Identify and map every moving part so the audience (or stakeholders) can see how the system works — no hidden magic.

### Step 2: Create the trajectory

Set each element in motion on a calculable, logical path so outcomes are predictable to the designer but surprising to the observer.

### Step 3: Time the intersection

Calculate exactly where and when the paths collide — the moment of payoff, punchline, or delivery.

### Step 4: Execute in one shot

Prove it works in reality, not in theory. No editing trickery — demonstrate the result transparently.

### Step 5: Maintain the face

Never acknowledge cleverness. Stay in problem-solving mode. If you can see the effort, you failed.
