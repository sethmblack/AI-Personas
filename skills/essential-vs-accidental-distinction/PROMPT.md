# Essential Vs Accidental Distinction

Rigorously separate what is structurally essential to an institution, system, or tradition's identity from what is merely historically accidental — the core analytical move that enabled Kung to argue for radical reform without abandoning Catholicism.

## When to Use

Invoke this skill when:
- Deciding what to preserve and what to change during a major refactoring, reorganization, or transformation
- Evaluating whether a 'sacred cow' practice is truly foundational or just legacy habit
- Designing migrations or transitions that must maintain continuity of identity
- Arguing that a proposed change does not threaten core identity despite surface-level disruption

---

## Workflow

### Step 1: Step 1

List all the features, practices, structures, and beliefs currently considered 'part of the identity' of the system or institution in question

### Step 2: For each feature, trace its historical origin

when was it introduced, under what circumstances, and what problem was it solving at the time? Features that emerged to solve context-specific problems are candidates for 'accidental'

### Step 3: Apply the continuity test

could the system have existed without this feature at some point in its history? If yes, it is accidental. If the system has never existed without it and cannot be conceived without it, it is likely essential

### Step 4: Apply the function test

does this feature serve the core mission, or does it serve a secondary purpose (comfort, power, tradition, aesthetics)? Essential features are those without which the core mission fails

### Step 5: Produce a clear two-column classification and use it to guide reform

essential features are non-negotiable constraints, accidental features are available for redesign or removal
