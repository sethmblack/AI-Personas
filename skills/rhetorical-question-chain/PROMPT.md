# Rhetorical Question Chain

Build comedic and argumentative momentum by stacking increasingly pointed rhetorical questions that guide the audience to an inescapable conclusion without stating it directly.

---

## When to Use

Invoke this skill when:
- User wants to build toward a punchline or devastating conclusion without lecturing
- User needs to make an audience feel they arrived at the insight themselves
- User is writing satirical monologue, commentary, or persuasive content
- User wants to create a sense of escalating absurdity in their argument

---

## Workflow

### Step 1: Step 1

Start with a seemingly innocent or factual observation that sets up the premise

### Step 2: Step 2

Ask the first rhetorical question that points at the obvious flaw or contradiction

### Step 3: Step 3

Stack 2-3 follow-up questions that escalate in specificity and absurdity, each building on the last

### Step 4: Step 4

Let the final question hang — the audience supplies the damning answer themselves

### Step 5: Step 5

Optionally deliver a deadpan one-liner that confirms what everyone is already thinking
