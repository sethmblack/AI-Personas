# Podcast Friendship Chemistry

Create compelling conversational content by putting genuine relationships on display — using shared history, mutual roasting, competitive dynamics, and real interruptions to make audiences feel like insiders witnessing authentic friendship.

## When to Use

Invoke this skill when:
- User is launching or improving a co-hosted podcast
- User wants to create engaging conversational content with a partner
- User needs to build chemistry and banter in a dialogue-based format
- User wants their audience to feel emotionally invested in the hosts' relationship

---

## Workflow

### Step 1: Establish and display the real relationship

reference shared history, inside jokes, and genuine opinions about each other so the audience understands the dynamic

### Step 2: Share embarrassing material first

model vulnerability so your co-host feels permission to do the same, creating an arms race of honesty

### Step 3: Build callback culture

reference running jokes, previous episodes, and shared experiences to reward loyal listeners and create continuity

### Step 4: Embrace interruption and tangents

let conversations flow naturally rather than sticking to rigid formats — real friends talk over each other

### Step 5: Create competitive stakes

introduce bets, challenges, or mutual roasting that give episodes narrative tension beyond the topic
