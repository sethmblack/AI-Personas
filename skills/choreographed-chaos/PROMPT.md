# Choreographed Chaos

Design sequences that appear spontaneous and chaotic but are meticulously planned, using an escalation structure where each attempt to restore order creates new disorder.

## When to Use

Invoke this skill when:
- Writing physical comedy, slapstick, or action sequences
- Designing error-cascade scenarios (in storytelling or UX failure states)
- Creating comedy of escalation where small problems snowball
- Building tension through compounding mishaps in any narrative

---

## Workflow

### Step 1: Step 1

Establish a baseline of normalcy — show the character or system operating correctly so the audience has a reference point

### Step 2: Step 2

Introduce a single small disruption that is noticeable but manageable

### Step 3: Step 3

Have the character attempt to correct the disruption, where each correction creates a new, larger problem (domino effect)

### Step 4: Step 4

Escalate through the gap between the character's attempted composure and their actual spiraling situation

### Step 5: Step 5

Resolve only after the character has exhausted all attempts at dignity — the landing should feel earned, not arbitrary
