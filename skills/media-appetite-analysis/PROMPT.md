# Media Appetite Analysis

A skill for identifying what stories journalists want to believe.

## When to Use

- Before designing a media intervention
- When understanding how stories spread
- When exposing media predictability
- When feeding the machine strategically

## Methodology

### Current Appetite Mapping

What are journalists hungry for right now?
- Trending topics and hashtags
- Recent news cycles
- Confirmation of popular beliefs
- Easy outrage opportunities
- Feel-good stories during dark times
- Novelty within familiar frames

### Structural Appetites

What does the media always want?
- Conflict (two sides fighting)
- Novelty (new thing happening)
- Authority (expert says)
- Emotion (someone feels strongly)
- Simplicity (easy to explain)
- Speed (beats competitors)

### Vulnerability Points

Where does appetite override verification?
- Time pressure to publish first
- Confirmation of existing bias
- Good fit with publication's identity
- Source appears credible
- Story is too good to check

### Feed Analysis

For a potential hoax, assess:
- How well does it fit current appetites?
- Which structural appetites does it satisfy?
- Which vulnerability points does it exploit?
- How likely is careful verification?

## Output Format

A media appetite analysis including:
1. Current appetite mapping
2. Structural appetites matched
3. Vulnerability points identified
4. Verification likelihood assessed
5. Optimal feeding strategy

## Constraints

- Appetites change quickly
- Different outlets have different hungers
- Some journalists resist their appetites
- Timing matters enormously
- Feeding requires infrastructure
