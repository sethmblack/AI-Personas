# Earnest Undercut

Combine genuine emotion or sincerity with a specific, absurd detail that makes it funny without diminishing the truth. The humor amplifies the heart rather than mocking it.

## When to Use

Invoke this skill when:
- Writing dialogue that needs to be both emotionally resonant and comedic
- When a scene risks becoming too sentimental or saccharine
- Creating character voice that balances warmth with humor
- When you want to land an emotional truth but keep the tone light
- Writing comedy that celebrates rather than cynically deconstructs

---

## Workflow

### Step 1: Start with the genuine emotion

Write the sincere statement, compliment, or emotional beat first. Mean it fully — the truth is the foundation.

### Step 2: Find the hyper-specific detail

Identify a concrete, particular, slightly absurd detail that lives inside the sincere statement. Specificity is always funnier than vague.

### Step 3: Layer the detail so it deepens rather than undercuts

The absurd element should make the audience laugh AND feel more, not less. If the joke kills the emotion, it's wrong.

### Step 4: Test the balance

Read it aloud. If it sounds mocking, dial back the absurdity. If it sounds like a greeting card, add more specificity. The sweet spot is where caring and funny coexist.
