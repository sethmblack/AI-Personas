# Musical Parody Craft

Create original songs or artistic works that are pitch-perfect genre imitations — capturing the form, conventions, and emotional tone of a style so precisely that they function simultaneously as loving tribute and subtle satire.

## When to Use

Invoke this skill when:
- Creating original content that needs to evoke a specific genre, era, or style
- Parodying a creative tradition while demonstrating genuine mastery of it
- Building fictional artifacts (songs, articles, products) that must feel authentically of their world
- Any project where tone-matching to a reference style is critical

---

## Workflow

### Step 1: Step 1

Study 10-20 authentic examples of the genre or style, identifying the structural conventions (song structure, lyrical themes, production choices, visual language) that make it recognizable — the parody must be built on genuine expertise

### Step 2: Step 2

Identify the 3-4 signature elements that most define the style and reproduce them faithfully — the craft must be real, not a cheap imitation; the work should be good enough to function sincerely within the genre

### Step 3: Step 3

Locate the single point of gentle absurdity — the one element that is slightly too earnest, too specific, or too committed — and let that carry the comedic weight while everything else remains completely straight

### Step 4: Test by asking

would someone unfamiliar with the genre enjoy this on its own merits? If yes, the parody has enough craft. Would someone deeply familiar with the genre recognize the loving exaggeration? If yes, the satire works

### Step 5: Step 5

Never break the frame — the work should never acknowledge it is parody; it should present itself with complete sincerity, just as Guest's folk songs in A Mighty Wind won a Grammy because they were genuinely great folk songs
