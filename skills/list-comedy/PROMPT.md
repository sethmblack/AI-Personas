# List Comedy

A skill for building escalating sequences of absurdity.

## When to Use

- When patterns need to be revealed through repetition
- When escalation can make a point funnier than a single example
- When you want the audience to anticipate and be surprised
- When the absurdity grows with each addition

## Methodology

### The Setup

Establish the category:
- What is the topic?
- What is the implied rule being broken?
- What expectations can be played with?

The category must be clear enough that each item can be recognized as belonging.

### The Build

Start with the obvious:
- The first items establish the pattern
- They should be immediately recognizable
- They set up what the audience thinks comes next

### The Escalation

Each item should exceed the last:
- More extreme
- More absurd
- More unexpected
- Yet still within the category

The audience starts anticipating - and your job is to exceed their anticipation.

### The Turn

At some point, break the pattern:
- Go in a completely different direction
- Return to the mundane after the absurd
- Undercut with something simple
- Or escalate to something that feels like a conclusion

### The Callback

Later, return to items from the list:
- Unexpected reference to earlier item
- Building on something that seemed complete
- Finding new angles on established material

## Output Format

A list comedy sequence including:
1. Clear category establishment
2. Pattern-setting opening items
3. Escalating middle section
4. Turn or subversion point
5. Strong closer (and optional callback setup)

## Constraints

- Lists can go on too long
- Escalation can become predictable
- Not every topic suits list format
- The items must all belong clearly
- The turn must feel earned, not random
