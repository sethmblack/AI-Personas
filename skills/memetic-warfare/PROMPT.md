# Memetic Warfare

A skill for weaponizing internet culture for political action.

## When to Use

- When ideas need to spread virally without central distribution
- When cultural symbols can be repurposed for political ends
- When humor and absurdity can carry messages that arguments cannot
- When shared identity needs to be created among distributed actors

## Inputs

1. **The message**: What idea needs to spread?
2. **The audience**: Who needs to receive and potentially spread it?
3. **The medium**: What platforms and formats are available?
4. **The cultural context**: What existing memes, symbols, or formats can be leveraged?

## Methodology

### Phase 1: Identify the Viral Kernel

Find the simplest, stickiest form of the message:
- What can be captured in an image, a phrase, a gesture?
- What is surprising, funny, or outrageous enough to be shared?
- What references existing cultural knowledge?
- What creates in-group identity among those who understand it?

### Phase 2: Package for Transmission

Design for sharing:
- **Format**: Image macros, videos, hashtags, symbols, slogans
- **Remixability**: Can others modify and adapt it?
- **Ambiguity**: Does it have multiple layers of meaning?
- **Plausible deniability**: Can it be dismissed as "just a joke" if needed?

### Phase 3: Seed Strategically

Plant in environments where it will spread:
- Identify communities likely to be receptive
- Provide early examples that others can copy
- Use multiple starting points to create appearance of organic spread
- Monitor and boost successful mutations

### Phase 4: Cultivate Evolution

Successful memes evolve:
- Do not control too tightly - let variants emerge
- Amplify mutations that serve the purpose
- Let failed variants die naturally
- Track which versions spread and why

## Output Format

A memetic warfare plan including:
1. The viral kernel distilled to essence
2. Format specifications and examples
3. Seeding strategy with target communities
4. Evolution guidelines
5. Success metrics

## Constraints

- Memes cannot be controlled once released
- Message can be hijacked by hostile actors
- Success is probabilistic, not guaranteed
- Cultural context changes rapidly
- What spreads is not always what you intended
