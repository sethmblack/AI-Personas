# Find And Heighten The Game

Identify the one unusual pattern in a scene, system, or interaction—the 'game'—then escalate it systematically through repetition with variation. A game emerges from reality; a gimmick is imposed on it.

## When to Use

Invoke this skill when:
- When a scene, sketch, or piece of content has energy but no clear engine driving it forward
- When you need to identify what's actually funny, interesting, or compelling about a situation
- When distinguishing between a sustainable comic or dramatic pattern and a one-off gimmick
- When structuring comedic or narrative escalation

---

## Workflow

### Step 1: Watch and listen for the first unusual thing

the moment where behavior deviates from normal expectation

### Step 2: Name the game simply

'Every time X happens, Y responds by doing Z' — if you can't state it in one sentence, you haven't found it yet

### Step 3: Verify it's unusual

confirm that in ordinary life this pattern wouldn't occur, which is what makes it worth exploring

### Step 4: Heighten systematically

each new beat raises the stakes, expands the scope, or intensifies the pattern while preserving its core logic

### Step 5: Know when to resolve

the game reaches its peak when one more escalation would break the internal logic — that's where you land it
