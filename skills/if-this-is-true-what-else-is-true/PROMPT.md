# If This Is True What Else Is True

Take any established fact and mine its implications ruthlessly, asking what else must logically exist given that fact. Specificity creates reality, reality creates investment, investment creates stakes.

## When to Use

Invoke this skill when:
- When building out a character, world, scenario, or concept from a single detail
- When a premise feels thin or underdeveloped
- When brainstorming needs more depth rather than more breadth
- When exploring the consequences of a design decision, plot point, or assumption

---

## Workflow

### Step 1: Step 1

Accept the established fact fully without hedging (e.g., 'This character is afraid of birds')

### Step 2: Ask the question

if this is true, what else must be true in this person's life, world, or system?

### Step 3: Follow the implications across multiple domains

relationships, daily routines, history, limitations, hidden capabilities

### Step 4: Step 4

Layer the reality by adding the strongest implications back into the work

### Step 5: Step 5

Repeat the process on the new facts you've generated, building compound specificity
