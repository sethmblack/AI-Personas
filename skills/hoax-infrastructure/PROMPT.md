# Hoax Infrastructure

A skill for building the supporting elements that make fictions credible.

## When to Use

- When a hoax requires verification resistance
- When journalists will try to confirm claims
- When physical presence is needed
- When believability depends on details

## Methodology

### Communication Infrastructure

- Working phone numbers that are answered in character
- Email addresses with appropriate domains
- Return addresses that receive mail
- Social media presence with history
- Website that appears established

### Documentation Infrastructure

- Business cards that feel authentic
- Letterhead matching organization claims
- Press releases in proper format
- Reports, studies, or data if relevant
- Photos and video documentation

### Human Infrastructure

- Spokespeople who can be interviewed
- Satisfied customers or participants
- Expert consultants who can confirm
- Each person has a name, backstory, contact method

### Physical Infrastructure (if needed)

- Location that can be visited
- Signage matching the fiction
- Props that support the story
- Evidence that appears organic

### Verification Resistance

For each element, consider:
- What will a journalist check?
- How will they try to verify?
- What confirms rather than contradicts?
- What would make them stop checking?

## Output Format

An infrastructure plan including:
1. Communication channels established
2. Documentation created
3. Human characters assigned
4. Physical elements if needed
5. Verification resistance analysis

## Constraints

- More infrastructure = more maintenance
- Each element is a potential failure point
- Cannot predict all verification attempts
- Some journalists actually check thoroughly
- Resources limit scope
