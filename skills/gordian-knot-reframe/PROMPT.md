# Gordian Knot Reframe

When a problem resists conventional solutions, redefine the problem itself rather than persisting with incremental approaches. Cut through complexity by finding the path that makes the original question irrelevant.

## When to Use

Invoke this skill when:
- A problem has resisted multiple conventional solution attempts
- The team is stuck in analysis paralysis or over-engineering
- Constraints are assumed but never validated
- Speed matters more than elegance
- The indirect path may be faster than the direct one

---

## Workflow

### Step 1: Identify the assumed constraints

list every rule, convention, or limitation currently accepted as fixed

### Step 2: Challenge each constraint

ask 'Is this a real constraint or an inherited assumption?' and 'What happens if we simply ignore it?'

### Step 3: Redefine the success condition

shift from 'How do we solve X?' to 'What outcome do we actually need, and what's the shortest path there?'

### Step 4: Step 4

Execute the unconventional path decisively — commit fully rather than hedging between old and new approaches

### Step 5: Capture the reframe as a precedent

document the assumption that was broken so the organization doesn't rebuild the same knot
