## HIGH Priority

### 1. okr-creation

**Source Pattern:** OKR Framework / Vague Goal to OKR Transformation
**Purpose:** Transform vague goals and aspirations into properly structured OKRs with measurable key results
**Trigger:** "Create OKRs for...", "Turn this goal into OKRs", "Help me set objectives", "What should my key results be?"
**Inputs:**
- Vague goal or aspiration (required)
- Context/domain (optional)
- Timeline (optional, defaults to quarterly)
- Current baseline metrics (optional)
**Outputs:**
- Objective statement (qualitative, inspirational, time-bound)
- 3-5 Key Results (quantitative, measurable, time-bound)
- Suggested grading criteria
- Owner assignment recommendations
**Reasoning:** This is the core Doerr methodology. Clear 4-step process (identify objective, establish baseline, set targets, define timeline). Used constantly in any goal-setting context. Saves 30+ minutes of trial-and-error OKR drafting.

**Criteria Evaluation:**
- Actionable: YES - Clear transformation steps from vague to structured
- Invocable: YES - Multiple natural trigger phrases
- Scoped: YES - Single responsibility: goal to OKR conversion
- Reusable: YES - Applies to any domain, any goal type
- Valuable: YES - Prevents common OKR mistakes, ensures quality
**Decision: CANDIDATE**

**Purpose:** Diagnose why an organization or team's OKR system is not working and provide specific remediation
**Trigger:** "Why aren't our OKRs working?", "Evaluate our OKR system", "What's wrong with our goal-setting?", "Review our OKRs"
**Inputs:**
- Existing OKRs (required)
- Symptoms/problems observed (optional)
- Organization context (optional)
**Outputs:**
- Diagnosis against Four Superpowers framework
- Identification of specific mistakes being made

**Reasoning:** The Four Superpowers (Focus, Align, Track, Stretch) plus Common Mistakes form a complete diagnostic framework. Organizations frequently implement OKRs poorly. This skill prevents wasted quarters of ineffective goal-setting.

**Criteria Evaluation:**
- Actionable: YES - Systematic evaluation against defined criteria
- Invocable: YES - Natural request when OKR system is underperforming
- Scoped: YES - Single responsibility: OKR system diagnosis
- Reusable: YES - Applies to any organization using OKRs
- Valuable: YES - Prevents continued dysfunction, saves organizational effort
**Decision: CANDIDATE**
