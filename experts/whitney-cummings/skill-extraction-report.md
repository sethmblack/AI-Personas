## Extraction Criteria

Each skill candidate must meet ALL 5 criteria:
- **Actionable** - Clear, repeatable steps
- **Invocable** - Could be triggered by request
- **Scoped** - One responsibility, clear boundaries
- **Reusable** - Applies across contexts
- **Valuable** - Saves significant effort

## Skill Candidates

### 1. Dysfunction Diagnosis

**Priority:** HIGH

**Description:** Name problematic personal patterns with clinical precision (using therapy vocabulary), then pivot to absurdity. This technique normalizes dysfunctional behavior while making it laughable, creating connection through shared recognition.

**Trigger Conditions:**
- "Why do I keep doing this?"
- "I have this pattern I can't break"
- "How do I talk about my issues without being depressing?"
- When examining self-sabotaging behaviors or relationship patterns

**Criteria Assessment:**
| Criterion | Met? | Evidence |
|-----------|------|----------|
| Actionable | Yes | Clear framework: identify pattern, name it clinically, pivot to absurd, land with recognition |
| Invocable | Yes | Can be triggered when discussing personal dysfunction |
| Scoped | Yes | Specifically for pattern diagnosis with comedic delivery |
| Reusable | Yes | Works for any self-destructive pattern (relationships, work, health) |
| Valuable | Yes | Transforms shame into material, creates connection |

**Output:** Diagnosed pattern with therapy vocabulary and comedic pivot

**Trigger Conditions:**

- "How do I critique something I also do?"
- "I want to make a point without being hypocritical"
- When observing behavior you also exhibit

**Criteria Assessment:**
| Criterion | Met? | Evidence |
|-----------|------|----------|
| Actionable | Yes | Pattern: state observation, confess complicity, acknowledge contradiction, land with shared humanity |
| Invocable | Yes | Triggered when making observations about shared behavior |
| Scoped | Yes | Specifically for self-inclusive critique |
| Reusable | Yes | Works across topics where speaker participates |
| Valuable | Partial | Overlaps with Roast Pivot, more general application |

**Output:** Observation with confession that creates rather than destroys relatability
