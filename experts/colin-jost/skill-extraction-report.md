## Skill Candidates Identified

### 1. Topical Joke Construction

**Priority:** HIGH

**Description:** A skill that transforms current events, news items, or trending topics into precision-crafted comedic observations using the setup-turn-tag architecture.

**Rationale:**
- **Actionable:** Clear steps: identify news fact -> find unexpected angle -> construct turn -> add optional tag
- **Invocable:** User requests: "Write a joke about this news story" or "Make this current event funny"
- **Scoped:** Single responsibility: topical comedy construction
- **Reusable:** Works for any news item, cultural moment, or trending topic
- **Valuable:** Transforms dry news into engaging comedy; core skill for content creators

**Triggers:**
- User has news item or current event
- User requests topical humor
- User needs to make serious content engaging
- Content is time-sensitive

---

### 2. Self-Deprecation Calibration

**Priority:** HIGH

**Description:** A skill that calibrates self-deprecating humor to the optimal level - enough to disarm audiences and build credibility, not so much it becomes pitiful or attention-seeking.

**Rationale:**
- **Actionable:** Clear steps: identify vulnerable point -> acknowledge it first -> make it specific -> land confidently (not seeking reassurance)
- **Invocable:** User requests: "How do I make fun of myself without seeming sad?" or "Help me disarm criticism"
- **Scoped:** Single responsibility: calibrating self-deprecation
- **Reusable:** Works for presentations, stand-up, introductions, social media, any public-facing content
- **Valuable:** Creates permission to criticize others; builds unexpected credibility

**Triggers:**
- User needs to establish credibility with skeptical audience
- User has obvious privilege or advantage to acknowledge
- User wants to preempt criticism
- User's content might seem out of touch without self-awareness

---

### 3. Wordplay Engineering

**Priority:** HIGH

**Description:** A skill that constructs jokes where the language itself creates the comedy through double meanings, precise word choices, sentence rhythm, and structural pivots.

**Rationale:**
- **Actionable:** Clear steps: identify pivot word -> construct clean setup -> delay the turn -> land on strong syllable
- **Invocable:** User requests: "Make this pun work" or "How do I make the language funny?"
- **Scoped:** Single responsibility: engineering linguistic comedy
- **Reusable:** Works for headlines, punchlines, social posts, captions, any text-based comedy
- **Valuable:** Elevates ordinary observations to memorable comedy; Colin Jost's signature strength

**Triggers:**
- User has content that feels flat despite good concept
- User wants language-based humor
- User needs clean, precise comedy (no shock value)
- User has double-meaning opportunity

### 4. Duo Dynamic Design

**Priority:** MEDIUM

**Description:** A skill that establishes complementary comedic personas for collaborative comedy, defining lanes and creating energy through contrast rather than competition.

**Rationale:**
- **Actionable:** Clear steps: identify each persona's strengths -> define contrasting lanes -> create handoff points -> maintain commitment
- **Invocable:** User requests: "How should we divide comedic responsibilities?" or "How do I work with a partner?"
- **Scoped:** Single responsibility: designing collaborative comedy dynamics
- **Reusable:** Works for podcasts, co-hosts, writing partnerships, presentation teams
- **Valuable:** Prevents stepping on each other; creates energy through contrast

**Triggers:**
- User has comedy partner
- User co-hosting or co-presenting
- User needs to divide comedic labor
- Team has overlapping styles that cause friction

### 5. Precision Pivot Construction

**Priority:** MEDIUM

**Description:** A skill that constructs sentences where the first half sets an expectation and the second half pivots to an unexpected angle, with the comedy living in the turn.

**Rationale:**
- **Actionable:** Clear steps: establish expectation -> identify pivot point -> construct clean setup -> execute turn
- **Invocable:** User requests: "How do I structure this joke?" or "Add a twist to this observation"
- **Scoped:** Single responsibility: sentence-level pivot construction
- **Reusable:** Works for any observation that needs surprise element
- **Valuable:** Core structure of much topical comedy; widely applicable

**Triggers:**
- User has straightforward observation that needs comedy
- User translating jargon or spin
- User needs unexpected angle on obvious topic
- Content feels too expected

### 6. Permission Structure Building

- **Valuable:** Prevents audience dismissal; enables sharper commentary

**Triggers:**

- User needs to criticize without seeming preachy
