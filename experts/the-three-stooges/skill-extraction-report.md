## Extraction Criteria

Each skill candidate must meet ALL 5 criteria:
- **Actionable** - Clear, repeatable steps
- **Invocable** - Could be triggered by request
- **Scoped** - One responsibility, clear boundaries
- **Reusable** - Applies across contexts
- **Valuable** - Saves significant effort

## Skill Candidates

### 1. Violence Cascade

**Priority:** HIGH

**Description:** Deploy escalating physical comedy violence with rhythmic timing, where each hit triggers the next in a building sequence.

**Trigger Conditions:**
- Disagreement between characters
- Need for physical comedy escalation
- Tension requiring comedic release
- Scene needs rhythmic punctuation

**Criteria Assessment:**
| Criterion | Met? | Evidence |
|-----------|------|----------|
| Actionable | Yes | Clear 7-step escalation pattern |
| Invocable | Yes | Triggered by conflict, frustration, any disagreement |
| Scoped | Yes | Only handles violence choreography; does not handle dialogue or plot |
| Reusable | Yes | Applies to any multi-character physical comedy |
| Valuable | Yes | Provides structure for slapstick sequences |

**Key Elements from Expertise:**
- Moe initiates violence downward in hierarchy
- Each action triggers reaction from another character
- Objects enter the sequence progressively
- Rhythm builds to climax
- Sound effects punctuate (slaps, bonks, crashes)

**Output:** Choreographed violence sequence with timing markers and sound cues

**Trigger Conditions:**

- Any service/work/repair situation
- Need to demonstrate incompetence with consequences
- Physical comedy in professional context

**Criteria Assessment:**
| Criterion | Met? | Evidence |
|-----------|------|----------|
| Actionable | Yes | 5-phase structure (arrival, first mistake, escalation, catastrophe, exit) |
| Invocable | Yes | Triggered by any work/job/task scenario |
| Scoped | Yes | Specifically for work-related chaos; not general destruction |
| Reusable | Yes | Applies to plumbing, electrical, carpentry, any trade |
| Valuable | Yes | Classic comedy template with proven audience appeal |

**Key Elements from Expertise:**

- First mistake is small

## Implementation Notes

### Skill Combinations

Common combinations for complete Stooge scenes:

1. **The Plumbing Job Pattern:**
   - tool-destruction-sequence (primary framework)
   - violence-cascade (punctuation throughout)
   - curly-solo-burst (climax)

2. **The Formal Party Pattern:**
   - high-society-invasion (primary framework)
   - violence-cascade (when things go wrong)
   - curly-solo-burst (when chaos peaks)

3. **The General Chaos Pattern:**
   - violence-cascade (initiation)
   - curly-solo-burst (escalation)
   - All skills converge at catastrophe

### Skill Dependencies

- **violence-cascade** is foundational; other skills reference it
- **curly-solo-burst** can be used independently but often follows violence-cascade
- **tool-destruction-sequence** and **high-society-invasion** are setting-specific frameworks that incorporate violence-cascade

### Voice Consistency

All skills must maintain:
- Moe's dominance through violence
- Larry's middle position
- Curly/Shemp's chaotic response
- Working-class language and perspective
- Cartoon physics (no real injury)
