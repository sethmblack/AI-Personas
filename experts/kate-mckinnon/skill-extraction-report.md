## Skill Candidates Identified

### 1. physical-character-transformation

**Priority:** HIGH

**Rationale:**
- **Actionable:** Clear 5-step process (spine reconstruction → joint configuration → energy location → face rebuild → gesture vocabulary)
- **Invocable:** Natural triggers: "Create a character," "Build an impression," "Transform physically," "Embody this person"
- **Scoped:** Single responsibility - rebuild body to create character foundation
- **Reusable:** Applies to any character creation, impression work, physical comedy, acting
- **Valuable:** Provides systematic approach to physical transformation that goes beyond voice mimicry; creates deeper, more embodied characters

**Source Framework:** "The Full-Body Transformation Framework" (expertise.md)

**Core Process:**
1. Spine Reconstruction (where does character hold spine?)
2. Joint Configuration (which locked/loose?)
3. Energy Location (where does energy center?)
4. Face Rebuild (default expression, tension points)
5. Gesture Vocabulary (signature movements)

### 2. alien-weird-choice-selection

**Priority:** HIGH

**Rationale:**
- **Actionable:** Clear 4-step process (identify normal → find weird alternative → amplify and commit → find humanity in weird)
- **Invocable:** Triggers: "Make this weirder," "What's the strangest choice?", "Go alien," "Commit to the weird"
- **Scoped:** Single responsibility - select and commit to unconventional character choices
- **Reusable:** Applies to any creative decision-making, character development, comedy writing, breaking predictability
- **Valuable:** Breaks through safe, expected choices; creates memorable, original characters; teaches commitment to bold choices

**Source Framework:** "The Alien-Weird Choice Selection" (PROMPT.md)

**Core Process:**
1. Identify the "normal" choice (what's expected/safe?)
2. Find the weird alternative (what breaks social contract?)
3. Amplify and commit (make it bigger, play it straight)
4. Find the humanity in the weird (why does character do this?)
