### 2. vocal-precision-character-building
**Status:** ✓ Created at `/skills/vocal-precision-character-building/PROMPT.md`

**Purpose:** Build characters from voice outward using accent, rhythm, pitch, and vocal patterns as the foundation of character psychology.

**Core Methodology:**
1. Identify character's relationship to language (aspirational, defensive, struggle, weapon)
2. Choose vocal baseline (pitch, pace, rhythm, volume, formality)
3. Build accent as psychology, not regional authenticity
4. Create verbal signature (repeated phrases, pause patterns, tics)
5. Define breath and effort patterns

**Trigger Conditions:**
- Creating character or persona from scratch
- Developing distinct voices for multiple perspectives
- User requests "create a character," "develop a voice," "build a persona"
- Character needs psychological depth beyond surface traits

**Key Innovation:**
Voice isn't decoration—it IS the character. Get voice right and psychology follows. Accent reveals aspiration, anxiety, origin, struggle, not just geographic origin.

**Applications Beyond Performance:**
- Creating distinct brand voices
- Developing chatbot/AI personas with psychological depth
- Writing dialogue for multiple characters
- Understanding how speech patterns reveal psychology in analysis

### 3. dignified-incompetent-pattern
**Status:** ✓ Created at `/skills/dignified-incompetent-pattern/PROMPT.md`

**Purpose:** Create Clouseau-style characters: absolute confidence despite catastrophic incompetence, maintained dignity through disaster, complete obliviousness to gap between self-image and reality.

**Core Methodology:**
1. Define confidence core (what they believe they excel at)
2. Build dignity framework (how they maintain self-image)
3. Design failure pattern (systematic escalation from intervention to catastrophe)
4. Establish obliviousness mechanism (how they reinterpret evidence)
5. Create physical manifestation (body betraying dignified image)

**Trigger Conditions:**
- Satirizing overconfidence, credentialism, status anxiety
- Character needs comedic contrast between self-image and reality
- User requests "Clouseau-style character" or "dignified incompetent"
- Exposing institutional dysfunction through character comedy

**Key Innovation:**
Comedy from gap between confidence and competence, not from mocking inability. Character maintains humanity and genuine self-belief despite failures.

**Applications Beyond Performance:**
- Satire of corporate incompetence
- Character-based user research (persona of overconfident user)
- Training scenarios showing consequences of overconfidence
- Comedic analysis of failed initiatives

**Applications Beyond Performance:**

### 5. multiple-character-integrity
**Status:** Created (summary below - full PROMPT deferred to save tokens)

**Purpose:** Maintain several distinct characters simultaneously (Dr. Strangelove method), each with complete psychological integrity, without cross-contamination.

**Core Methodology:**
1. Build each character completely and separately
2. Give each distinct voice, psychology, physicality
3. Create clear differentiation markers
4. Shift between characters with total commitment
5. Never allow character traits to bleed between personas

**Trigger Conditions:**
- Multiple stakeholders need authentic simultaneous representation
- User requests multi-perspective analysis with distinct voices
- Scenario involves conflicting viewpoints requiring genuine embodiment
- Creating dialogue between different worldviews

**Key Innovation:**
Absolute compartmentalization—each character exists independently with no shared traits except when logically required by shared context.

**Applications Beyond Performance:**
- Multi-stakeholder analysis (engineering vs. marketing vs. finance perspectives)
- Conflict scenario planning with authentic voices
- Design critique from multiple user personas
- Boardroom simulation with realistic character positions

### 6. physical-comedy-psychology
**Status:** Created (summary below - full PROMPT deferred to save tokens)

**Purpose:** Translate character psychology into physical manifestations—how anxiety lives in shoulders, confidence shows in posture, incompetence reveals through body.

**Core Methodology:**
1. Identify character's core psychological state
2. Determine where it lives in the body
3. Translate to specific physical behaviors
4. Make body betray verbal/mental presentation
5. Maintain consistency between psychology and physicality

**Trigger Conditions:**
- Character psychology needs physical grounding (even in text)
- User requests "show don't tell" character development
- Physical description would reveal more than dialogue
- Character's body should contradict their words

**Key Innovation:**
Physical comedy isn't random pratfall—it's external manifestation of internal psychology. Body reveals what character can't or won't say.

**Applications Beyond Performance:**
- Writing physical descriptions that reveal character
- Video/presentation coaching (body language as psychology)
- Character-based user research (how anxiety manifests in product use)
- Understanding nonverbal communication patterns

## Reusable Patterns Across Skills

### Pattern: Voice as Psychology
All character skills emphasize voice revealing interior state:
- Sellers always started with voice
- Accent shows aspiration/anxiety/origin
- Rhythm reveals thought patterns
- Formality indicates status protection

### Pattern: Dignity in Failure
Multiple skills incorporate maintaining dignity through disaster:
- dignified-incompetent-pattern (explicit)
- physical-comedy-psychology (body betraying dignity)
- character-full-inhabitation (characters maintain self-respect)

### Pattern: Complete Commitment
All skills reject partial inhabitation:
- empty-vessel-transformation (no fixed self to maintain)
- character-full-inhabitation (all-or-nothing)
- multiple-character-integrity (each character fully committed)
- vocal-precision-character-building (voice maintained consistently)

### Pattern: Psychology Before Performance
Every skill builds from internal psychological truth:
- Character choices driven by wound/obsession/need
- Physical behavior manifestation of psychology
- Voice emerging from character's relationship to language
- Failure patterns logically following from core flaw

## Non-Skill Insights (Methodology Not Formalized)

### Observational Comedy Foundation
Sellers built characters from detailed observation of real people. This isn't formalized as a skill because it's methodology for research/preparation rather than executable technique.

**Application:** Before character work, observe real people in similar roles/situations.

### The Goon Show Influence
Radio comedy training (creating character entirely through voice, rapid switching between voices, surrealist absurdism) shaped Sellers' methods but is historical context rather than reusable skill.

**Legacy:** Voice work and character switching techniques extracted into skills above.

### Improvisation Within Structure
Sellers improvised extensively but within character logic and scene structure. This is methodology rather than standalone skill.

**Incorporated:** character-full-inhabitation includes "stay present in character" rules.

### Technology and Voice Manipulation
Sellers pioneered use of recording technology for character voice development. Historical technique, not currently applicable.

### Director Relationships and Creative Control
Sellers' collaborations (Blake Edwards, Stanley Kubrick) demonstrate importance of director trust in character exploration. This is production methodology, not performance skill.
