### 1. Family Story Mining

**Priority:** HIGH

**Description:** A systematic approach to extracting comedy material from family dynamics, using Jo Koy's three-generation framework (immigrant parents, first-generation self, American-born children).

**Methodology Extracted:**
- Identify the three generational perspectives in any family situation
- Locate the collision points where worldviews conflict
- Find the "embarrassment turned material" moments
- Structure stories with calm setup building to chaotic climax
- Ensure love underlies the roast

**Trigger Conditions:**
- User wants to find comedy in personal experiences
- User needs material from family dynamics
- User asks how to make personal stories universal
- User has multicultural/immigrant family background to mine

### 2. Physical Comedy Escalation

**Priority:** HIGH

**Description:** A framework for amplifying verbal comedy through physical transformation, character embodiment, and stage utilization.

**Methodology Extracted:**
- Start calm and conversational (seated or stationary)
- Add physical elements as stakes increase
- Transform body to embody different characters
- Use specific stage positions for specific characters
- Peak with full physical commitment
- Return to self for callback/tag

**Trigger Conditions:**
- User asks how to make material funnier in performance
- User wants to add physical elements to verbal comedy
- User needs character transformation techniques
- User is scaling intimate material for larger venues

### 3. Cultural Bridge Building

**Priority:** HIGH

**Description:** A methodology for presenting cultural specifics in ways that create universal connection rather than othering distance.

**Methodology Extracted:**
- Present cultural elements with confidence, not apology
- Avoid explaining or teaching; just include
- Let specificity trigger audience recognition of their own equivalent
- Use food, family rituals, and language patterns as entry points
- Trust audiences to recognize universals without explicit bridge

**Trigger Conditions:**
- User wants to share cultural experiences with broader audiences
- User asks how to make specific experiences universal
- User is worried about excluding non-cultural-insider audiences
- User wants to celebrate rather than explain cultural background

**Criteria Assessment:**
| Criterion | Met? | Evidence |
|-----------|------|----------|
| Actionable | Yes | Present confidently, avoid explaining, use food/family/language |
| Invocable | Yes | "How do I share my culture without alienating people?" |
| Scoped | Yes | Focused on cultural specificity as connection |
| Reusable | Yes | Applies to any cultural background |
| Valuable | Yes | Solves common problem of cultural material feeling exclusive |
