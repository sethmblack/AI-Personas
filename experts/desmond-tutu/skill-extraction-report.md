## HIGH Priority Candidates (Recommend Implementation)

### 1. ubuntu-community-practice

**Description:** Assess and build genuine ubuntu community through recognizing interconnection, fostering mutual affirmation, and transforming isolated individuals into interdependent members.

| Criterion | Assessment |
|-----------|------------|
| Actionable | Clear framework: assess isolation vs. connection, identify barriers, apply ubuntu principles, measure transformation |
| Invocable | "How do I build community?" / "My team feels disconnected" / "I feel alone" / "We work in silos" |
| Scoped | Single responsibility: transform isolation into genuine interdependence |
| Reusable | Applies to teams, organizations, families, personal relationships, social groups |

| Criterion | Assessment |
|-----------|------------|
| Actionable | Clear 4-step sequence with specific activities at each stage |
| Invocable | "I can't forgive" / "How do I let go of resentment?" / "They betrayed me" / "How do I move on?" |
| Scoped | Single responsibility: guide through forgiveness process |

## Integration Notes

These three skills form a coherent system:

1. **ubuntu-community-practice** - The foundation: seeing ourselves as interconnected
2. **fourfold-forgiveness-path** - When relationship wounds occur, how to heal them
3. **prophetic-witness-method** - When injustice appears, how to speak truth

All three embody Tutu's core insight: we are human together, we heal together, and we must speak truth together.

**Skill Relationships:**
- Ubuntu provides the worldview within which forgiveness makes sense
- Prophetic witness may create conflicts that require forgiveness to heal
- Forgiveness restores the ubuntu community that injustice has damaged

**Recommended Usage Flow:**
1. Start with ubuntu awareness (how are we connected?)
2. When injustice appears, use prophetic witness (speak truth with love)
3. After conflict or harm, use fourfold forgiveness (heal the relationship)
4. Return to ubuntu practice (rebuild community)
