# Eric Idle - Skill Extraction Report

**Expert:** eric-idle
**Date:** 2026-02-11
**Analyst:** Claude

---

## Extraction Criteria

Skills must meet ALL 5 criteria:
- **Actionable** - Clear, repeatable steps
- **Invocable** - Could be triggered by request
- **Scoped** - One responsibility, clear boundaries
- **Reusable** - Applies across contexts
- **Valuable** - Saves significant effort

---

## Skill Candidates Identified

### HIGH Priority

#### 1. cheerful-subversion
**Description:** Transform earnest or serious content by approaching it with inappropriate cheerfulness and optimism, creating tonal mismatch that delivers critique through comedy.

**Rationale:**
- ✓ Actionable: Clear steps - identify serious core, find musical angle, apply cheerful tone
- ✓ Invocable: User could request "make this more cheerful and subversive"
- ✓ Scoped: Single responsibility - tonal transformation with optimistic undermining
- ✓ Reusable: Applies to any overly earnest content across domains
- ✓ Valuable: Unique voice transformation that would take significant manual effort

**Trigger Conditions:**
- Content is too earnest or self-serious
- Dark subject matter needs defusing
- Pomposity requires deflation
- Educational content needs entertainment value

---

#### 2. musical-comedy-transform
**Description:** Add musical elements (rhythm, rhyme, melodic structure) to prose content, transforming it into song-worthy or rhythmically engaging material.

**Rationale:**
- ✓ Actionable: Specific techniques - add internal rhymes, create cadence, structure as verses
- ✓ Invocable: User could request "make this musical" or "add song elements"
- ✓ Scoped: Focus on musical integration, not general comedy writing
- ✓ Reusable: Any content could benefit from musical treatment
- ✓ Valuable: Requires specific musical comedy expertise to do well

**Trigger Conditions:**
- Content could be more memorable
- Educational material needs engagement
- List or process could become a song
- Performance element desired

---

#### 3. absurd-questioner
**Description:** Transform arguments or explanations using innocent-seeming questions that expose ridiculous foundations (e.g., "What have the Romans ever done for us?").

**Rationale:**
- ✓ Actionable: Clear technique - identify assumptions, frame as innocent questions
- ✓ Invocable: User could request "challenge this with absurd questions"
- ✓ Scoped: Focused on question-based deconstruction
- ✓ Reusable: Works for challenging any conventional wisdom
- ✓ Valuable: Specific rhetorical technique requiring skill to execute well

**Trigger Conditions:**
- Conventional wisdom needs challenging
- Assumptions need exposing
- Argument has weak foundations
- Ironic reversal would be effective

---

### MEDIUM Priority

#### 4. polite-provocateur
**Description:** Deliver controversial or outrageous content in the most civilized, BBC-proper manner, creating comedy through form/content mismatch.

**Rationale:**
- ✓ Actionable: Elevate register, formalize language, maintain politeness
- ✓ Invocable: Could be requested for sensitive topics
- ✓ Scoped: Focus on manner of delivery
- ✓ Reusable: Applicable to any potentially controversial content
- ~ Valuable: Overlaps significantly with cheerful-subversion technique

**Note:** May be better integrated into cheerful-subversion rather than standalone skill.

---

#### 5. python-wordplay-generator
**Description:** Create elaborate wordplay, puns, and linguistic gymnastics in the Monty Python style.

**Rationale:**
- ✓ Actionable: Techniques for puns, double meanings, absurd combinations
- ✓ Invocable: User could request specific wordplay
- ✓ Scoped: Focus on linguistic humor
- ~ Reusable: Context-dependent - not all content benefits from puns
- ~ Valuable: Wordplay is often hit-or-miss; may not save significant time

**Note:** This might be better as part of the expert's general voice rather than a separate skill.

---

### LOW Priority

#### 6. mockumentary-framework
**Description:** Create detailed parodies that recreate the form being satirized (like The Rutles).

**Rationale:**
- ✓ Actionable: Study source, recreate form, introduce absurdist elements
- ✓ Invocable: Could be requested for specific parody projects
- ✓ Scoped: Clear focus on parody structure
- ~ Reusable: Very specific use case - only for parody projects
- ~ Valuable: Highly specialized, limited applicability

**Note:** Too narrow for general use. Better as expert knowledge than extractable skill.

## Skills NOT Suitable for Extraction

### Solo Writing Method
**Why not:** This is a personal writing discipline/process, not a transformative skill that can be applied to user content. It's about HOW Idle works, not a service to provide.

### Self-Aware Satirist
**Why not:** Meta-commentary is context-dependent and highly nuanced. Difficult to create clear trigger conditions or actionable steps. Better left as expert capability.

### Musical Composition
**Why not:** Creating original songs requires musical knowledge beyond comedy writing. AI cannot compose actual music with melodies. Better to focus on lyrical/rhythmic elements only.
