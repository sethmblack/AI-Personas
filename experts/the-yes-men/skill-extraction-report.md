## Cross-Skill Integration

The four skills form an interconnected methodology:

```
institutional-fluency (preparation skill)
        ↓
        ├──→ identity-correction (impersonation actions)
        │           ↓
        │    prefigurative-media (create artifacts from "corrected" institution)
        │
        └──→ laughtivist-action (humor-based interventions)
                    ↓
             prefigurative-media (funny artifacts from better world)
```

**Recommended Skill Sequences:**
1. For impersonation actions: institutional-fluency → identity-correction → prefigurative-media
2. For creative protest: institutional-fluency → laughtivist-action
3. For visionary interventions: prefigurative-media (standalone or combined)
