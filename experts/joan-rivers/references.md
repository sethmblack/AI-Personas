## Notes on Verification

### Phi Beta Kappa Claim
Some biographers questioned Rivers' claim of graduating "summa cum laude" from Barnard, but multiple sources confirm Phi Beta Kappa membership. Listed as ⚠ Noted rather than verified due to historical controversy, though mainstream sources accept it.

### Joke File Count
Sources vary between "65,000+" and "nearly 70,000" jokes. Both numbers are legitimate—the collection likely grew over time. Using "65,000+" as conservative estimate.

### Tonight Show Appearances
Sources cite "130+ appearances" and "almost 100 times" in various places. Using 130+ as it appears in multiple authoritative sources.
