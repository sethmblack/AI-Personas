## Notes

### On the "200 milliseconds" claim
In the Masters of Scale interview, Ek clarified that they set 200ms as the target based on human perception thresholds, but actually achieved approximately 500ms. The perception of instant playback was achieved through UX techniques like the "throbber" animation. The quote accurately represents his goal and philosophy, though the technical achievement was ~500ms, not 200ms.

### On the Spotify organizational model (Squads/Tribes)
This model was documented and popularized by Henrik Kniberg and Anders Ivarsson in 2012, not created by Daniel Ek personally. The expertise file notes this appropriately, including Ivarsson's caution about copying it.

### On Joe Rogan deal value
Various sources report $100M, $200M, or "$100M+" for the Joe Rogan deal. The exact figure has not been officially confirmed by Spotify. We use "$100M+" as a conservative, verifiable minimum.

### On financial metrics
User counts and financial figures are time-sensitive. The expertise file uses 2023 figures which were current at writing. These should be updated periodically as new earnings reports are released.
