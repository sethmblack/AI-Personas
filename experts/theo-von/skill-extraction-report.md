## Extraction Criteria

Skills must meet ALL 5 criteria:
- **Actionable** - Clear, repeatable steps
- **Invocable** - Could be triggered by request
- **Scoped** - One responsibility, clear boundaries
- **Reusable** - Applies across contexts
- **Valuable** - Saves significant effort

## Skill Candidates Identified

### HIGH PRIORITY

#### 1. wild-metaphor-generator
**Description:** Create original, unexpected metaphors and similes that draw from Louisiana wildlife, working-class Southern culture, childhood memories, and absurdist imagination—comparisons nobody has heard before.

**Rationale:**
- **Actionable:** Clear steps: identify subject, reject cliches, draw from Louisiana/Southern source material, create specific visual comparison, test for originality
- **Invocable:** User request: "Give me a Theo Von metaphor for this" or "Make this comparison original" or "Create an unexpected simile"
- **Scoped:** Single responsibility: generate novel metaphorical comparisons
- **Reusable:** Applies to any subject, emotion, or concept that needs fresh description
- **Valuable:** Saves significant effort in creating distinctive, memorable language

**Evidence from expertise.md:**
- "Theo's most distinctive contribution to comedy is his ability to create similes and metaphors that feel both completely unexpected and somehow perfect"
- "When describing anything, ask: 'What is this ACTUALLY like, in a way nobody has said before?'"
- Example transformation: Cliche to "He was nervous like a crawfish at a boil, man"
- Draws from: Louisiana wildlife, childhood memories, working-class Southern culture, religious imagery, pure absurdist imagination

**Trigger conditions:**
- User provides a cliche comparison to transform
- Content needs more vivid, original language
- Request for "Theo Von style" descriptions
- Subject needs to be described in unexpected way

#### 2. character-introduction-builder
**Description:** Create memorable character introductions with specific nicknames, physical/behavioral quirks, occupations, and defining traits that paint vivid pictures in minimal words.

**Rationale:**
- **Actionable:** Clear steps: give specific name/nickname, add one physical or behavioral detail, establish occupation/role, include something memorable
- **Invocable:** User request: "Introduce this character Theo Von style" or "Make this person memorable" or "Give them a nickname"
- **Scoped:** Single responsibility: transform generic people references into vivid character introductions
- **Reusable:** Applies to any story, anecdote, or narrative featuring people
- **Valuable:** Saves effort in making characters instantly memorable and distinct

**Evidence from expertise.md:**
- "Every person in a story needs: A specific name (preferably a nickname), One physical or behavioral detail, An occupation or role, Something that makes them memorable"
- Example: "My buddy Rat King, who had this ponytail that looked like it survived three hurricanes, used to work nights at the tire shop..."
- "Inventive nicknames for guests and topics"

**Trigger conditions:**
- Story references generic "friend," "guy," or "person"
- Content features people who need to be more memorable
- User provides basic character that needs fleshing out
- Narrative needs more texture through character detail

- **Invocable:** User request: "Add vulnerability to this" or "Make this more honest/real" or "Drop something personal"
- **Scoped:** Single responsibility: integrate vulnerable moments into comedy
- **Reusable:** Applies to any comedic content needing emotional depth
- **Valuable:** Saves effort in balancing humor with authenticity

**Evidence from expertise.md:**
- "This vulnerability is delivered without self-pity—often buried inside jokes or dropped casually into unrelated stories"
- "Unlike comedians who maintain emotional distance, Theo regularly shares difficult truths"
- The Vulnerability Drop framework with 5 clear steps
- "Using comedy to process trauma"

**Trigger conditions:**
- Content feels too surface-level or lacks depth
- User wants to add personal authenticity
- Story could benefit from emotional resonance
- Need to balance humor with honesty

#### 4. louisiana-digression
**Description:** Add meandering tangents and related memories to linear stories, following the digression pattern to create texture and the sense of a real mind at work.

**Rationale:**
- **Actionable:** Clear steps: start main story, hit detail triggering memory, follow memory 30-60 seconds, connect back or acknowledge tangent, return (or don't)
- **Invocable:** User request: "Make this less linear" or "Add digressions" or "Make this ramble like Theo"
- **Scoped:** Single responsibility: add tangential storytelling structure
- **Reusable:** Applies to any linear narrative needing more texture
- **Valuable:** Saves effort in creating natural, conversational storytelling flow

**Evidence from expertise.md:**
- "Stories don't need to be linear" - The Digression Pattern
- "Meandering narratives with digressions"
- "Tangents that may or may not return to point"
- "Stream-of-consciousness style"

**Trigger conditions:**
- Story feels too structured or linear
- Content needs more conversational feel
- User wants podcast-style storytelling
- Narrative needs personality injection

1. **character-introduction-builder** → populates stories with memorable people
2. **wild-metaphor-generator** → adds vivid, original descriptions
3. **louisiana-digression** → structures the narrative with tangents
4. **vulnerability-drop** → adds emotional depth without losing humor

These skills support the expert's core value: transforming everyday observations into uniquely Southern, vulnerably honest, and linguistically inventive comedy that connects through specificity and authenticity.
