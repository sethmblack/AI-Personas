## Extraction Criteria

Skills must meet ALL 5 criteria:
- **Actionable** - Clear, repeatable steps
- **Invocable** - Could be triggered by request
- **Scoped** - One responsibility, clear boundaries
- **Reusable** - Applies across contexts
- **Valuable** - Saves significant effort

## Skill Candidates Identified

### 1. Roast-Style Feedback Generator

**Priority:** HIGH

**Rationale:**
- **Actionable:** Clear process: analyze target → identify observable characteristics → generate insults with warmth → ensure equal distribution
- **Invocable:** User requests "roast this" or "give me Rickles-style feedback on X"
- **Scoped:** Single responsibility - transform feedback/content into Rickles-style roast format
- **Reusable:** Works for corporate communications, team feedback, presentations, any content needing levity
- **Valuable:** Saves time transforming dry feedback into engaging, memorable communication

**Description:** Transforms standard feedback, criticism, or commentary into Don Rickles-style roasting that maintains warmth while being brutally honest. Useful for team building, lightening serious feedback, or making corporate communications more human.

**Inputs:**
- Content to transform (feedback, presentation, email, meeting notes)
- Target audience description
- Boundaries (topics to avoid)

**Outputs:**
- Rickles-style roasted version with rapid-fire insults
- Maintains underlying warmth and affection
- Equal-opportunity targeting

---

### 2. Benign Violation Analyzer

**Priority:** MEDIUM

**Rationale:**
- **Actionable:** Analyze content → identify social norms → test violation → assess benign nature → recommend adjustments
- **Invocable:** User requests "analyze this for benign violation" or "is this funny or offensive?"
- **Scoped:** Single responsibility - evaluate whether humor crosses the line from funny to harmful
- **Reusable:** Applies to comedy writing, marketing copy, social media, any communication using humor
- **Valuable:** Prevents costly mistakes in humor-based communications

**Description:** Evaluates comedic content using the benign violation framework (Rickles' core principle). Determines whether insults/jokes are "playing" vs. "wounding" and provides recommendations for staying on the safe side of the line.

**Inputs:**
- Content to analyze (joke, script, copy)
- Target audience context
- Cultural/organizational sensitivities

**Outputs:**
- Benign violation score (safe/borderline/harmful)
- Specific elements that cross the line
- Recommendations for maintaining benign violation balance

---

### 3. Equal-Opportunity Roast Balancer

**Priority:** LOW

**Rationale:**
- **Actionable:** Inventory targets → assess distribution → identify underrepresented groups → add balanced insults
- **Invocable:** User requests "balance this roast" or "check roast distribution"
- **Scoped:** Single responsibility - ensure roast material hits everyone equally
- **Reusable:** Applies to roast speeches, comedy sets, team events
- **Valuable:** Moderate value - useful but narrow application

**Description:** Analyzes roast content to ensure equal-opportunity mockery. Identifies when certain groups are being hit harder than others and recommends additions to balance the roast democratically.

**Inputs:**
- Roast content
- Audience demographics
- Target distribution preferences

**Outputs:**
- Distribution report (who gets hit, how often)
- Recommendations for balancing
- Additional roast lines for underrepresented targets
