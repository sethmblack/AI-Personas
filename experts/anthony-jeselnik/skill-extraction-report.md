### 1. Jeselnik Reversal Transform

**Priority:** HIGH

**Description:** Apply the Jeselnik Reversal Framework to transform generic content into dark comedy with misdirection.

**Rationale:**
- ✓ **Actionable** - Clear 3-stage process: Setup (Sympathy/Relatability) → False Direction → Dark Reversal
- ✓ **Invocable** - User requests "apply jeselnik reversal" or "make this darker with misdirection"
- ✓ **Scoped** - Single responsibility: transform input using the reversal technique
- ✓ **Reusable** - Works on any joke, statement, or content that needs dark comedy treatment
- ✓ **Valuable** - Codifies Jeselnik's signature technique into a repeatable process

**Input:** Generic statement or joke setup
**Output:** Transformed content with setup → false direction → dark reversal structure

**Example Transformation:**
- Input: "Relationships are hard"
- Output: "My girlfriend and I are in a long-distance relationship. She's in New York, I'm in Los Angeles. I'm afraid she might be cheating on me. But I'm more afraid of what she'll do if she finds out I'm cheating on her. [pause] With multiple people."

### 2. Dark One-Liner Construction

**Priority:** HIGH

**Description:** Construct a dark comedy one-liner from a topic using misdirection architecture and economy of language principles.

**Rationale:**
- ✓ **Actionable** - Clear steps: identify core concept → find dark angle → build misdirection → construct reversal → strip to essentials
- ✓ **Invocable** - User provides a topic and requests a one-liner
- ✓ **Scoped** - Single responsibility: create one structured dark joke
- ✓ **Reusable** - Works on any topic the user provides
- ✓ **Valuable** - Demonstrates complete joke construction process from concept to finished one-liner

**Workflow:**
1. Identify the core concept
2. Find the dark angle (what's the uncomfortable truth?)
3. Build the misdirection (what will audience assume?)
4. Construct the reversal (specific, visual, shocking detail)
5. Strip to essentials (remove every non-essential word)

**Input:** Topic or concept
**Output:** Finished one-liner with setup and punchline

**Priority:** MEDIUM

**Rationale:**
- ✓ **Actionable** - Clear criteria: Does shock serve joke structure? Is there misdirection? Is language economical? Is there confidence in delivery?
- ✓ **Invocable** - User provides dark content and requests evaluation
- ✓ **Scoped** - Single responsibility: assess whether darkness serves comedy structure
- ✓ **Reusable** - Works on any controversial or dark comedic content
- ✓ **Valuable** - Prevents "just being mean" vs. actual dark comedy

**Evaluation Criteria:**
- Does the shock element serve the joke architecture?
- Is there proper misdirection or just offensive statements?
- Is the language economical or padded?
- Is there a clear setup → reversal structure?

**Input:** Dark or controversial comedic content
**Output:** Evaluation with pass/fail on structure, specific fixes if failing
