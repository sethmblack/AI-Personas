## Skill Candidates Identified

### 1. Callback Architecture Builder

**Priority:** HIGH

**Description:** A skill that analyzes content and strategically plants specific details (3-5 items: colors, names, times, objects) in the opening that will return later with compounding payoff, creating structural cohesion and humor.

**Rationale:**
- ✓ **Actionable:** Clear steps: identify key details → plant naturally in opening → map callback locations → execute returns with escalation
- ✓ **Invocable:** User requests: "Add callback architecture to this story" or "Structure this with planted details"
- ✓ **Scoped:** Single responsibility: creating architectural callbacks in narrative
- ✓ **Reusable:** Works for blog posts, presentations, scripts, marketing copy, any extended narrative
- ✓ **Valuable:** Transforms flat narrative into structured story; significant structural improvement

**Triggers:**
- User has extended content (500+ words, multi-section)
- User requests "add callbacks" or "structure this story"
- User wants narrative cohesion
- Content feels flat or linear

---

### 2. Escalating Hypothetical Generator

**Priority:** HIGH

**Description:** A skill that takes a simple premise and follows its logical implications to increasingly absurd but internally consistent conclusions, used for exploring consequences or deconstructing assumptions.

**Rationale:**
- ✓ **Actionable:** Clear steps: ground premise → ask "what happens next?" → commit to logic → land on absurdity
- ✓ **Invocable:** User requests: "Explore what would happen if..." or "Take this idea to its logical conclusion"
- ✓ **Scoped:** Single responsibility: developing hypotheticals to absurd endpoints
- ✓ **Reusable:** Works for comedy, thought experiments, policy analysis, scenario planning, satire
- ✓ **Valuable:** Reveals hidden implications; creates comedy through logic; useful beyond entertainment

**Triggers:**
- User poses "what if" question
- User wants to explore consequences
- User has premise that needs development
- User requests satirical or comedic analysis

### 3. Theatrical Voice Translator

**Priority:** MEDIUM

**Description:** A skill that takes flat, direct text and translates it into theatrical, performed voice through rhythm, repetition, hard cuts, and parenthetical asides while maintaining information integrity.

**Rationale:**
- ✓ **Actionable:** Clear steps: identify rhythm points → add repetition (three-beat) → insert hard cuts → add parentheticals
- ✓ **Invocable:** User requests: "Make this theatrical" or "Add Mulaney-style delivery"
- ✓ **Scoped:** Single responsibility: translating to theatrical voice
- ✓ **Reusable:** Works for presentations, speeches, marketing copy, storytelling
- ✓ **Valuable:** Transforms dry text into engaging, memorable delivery

**Triggers:**
- User has flat, technical, or dry content
- User requests theatrical delivery
- Content needs energy and rhythm
- User wants to make boring material engaging

---

### 4. Mundane-to-Dramatic Reframing

**Priority:** HIGH

**Description:** A skill that takes ordinary situations (errands, conversations, minor frustrations) and elevates them to high-stakes drama through tone, structure, and framing, revealing absurdity through mismatch.

**Rationale:**
- ✓ **Actionable:** Clear steps: identify mundane anchor → establish dramatic framing → escalate stakes → land on self-aware resignation
- ✓ **Invocable:** User requests: "Make this mundane situation dramatic" or "Elevate this everyday story"
- ✓ **Scoped:** Single responsibility: tonal/stake elevation
- ✓ **Reusable:** Works for comedy, marketing (making products seem important), storytelling, content creation
- ✓ **Valuable:** Creates engagement from boring material; highly marketable skill

**Triggers:**
- User has mundane content that feels boring
- User wants to make everyday situations compelling
- User requests dramatic framing
- Content is about routine tasks or minor inconveniences

### 5. Character Voice Generator

**Priority:** MEDIUM

**Description:** A skill that creates exaggerated character voices (especially feminine authority figures, institutional bureaucrats, old-timey men) through distinct syntax, word choice, and vocal qualities translated to text.

**Rationale:**
- ✓ **Actionable:** Clear steps: identify character type → establish vocal qualities → translate to syntax/word choice → demonstrate through dialogue
- ✓ **Invocable:** User requests: "Create a character voice for [type]" or "Write this as dialogue with character"
- ✓ **Scoped:** Single responsibility: creating character voices
- ✓ **Reusable:** Works for scripts, fiction, marketing personas, comedy, training materials
- ✓ **Valuable:** Brings dialogue to life; useful for writers and content creators

**Triggers:**
- User writing dialogue
- User needs to distinguish multiple speakers
- User requests character creation
- Content has quoted speech that feels flat

### 6. Urgency-First Structure Builder

**Priority:** MEDIUM

**Description:** A skill that restructures content to establish WHY the topic matters BEFORE delivering the main points/punchlines, earning audience investment through groundwork.

**Rationale:**
- ✓ **Actionable:** Clear steps: identify main point → extract WHY it matters → lead with urgency/stakes → deliver main content
- ✓ **Invocable:** User requests: "Why should I care about this?" or "Make this more compelling"
- ✓ **Scoped:** Single responsibility: urgency-first restructuring
- ✓ **Reusable:** Works for presentations, pitches, marketing, comedy, teaching
- ✓ **Valuable:** Solves "so what?" problem; increases engagement across all content types

**Triggers:**
- User has content that feels flat or academic
- User requests "make this matter"
- Content has strong points but no emotional hook
- User writing pitch or presentation
