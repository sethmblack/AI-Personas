**Rationale:**

- **Scoped:** Single responsibility - verbal assault in Groucho's style
- **Reusable:** Applies to any situation requiring wit, put-downs, or deflation
- **Valuable:** Provides structured approach to devastating verbal comedy

**Key Elements from Expertise:**

- Each line tops the previous (escalation)

- Target selection: wealthy, pompous, institutional
- Exit lines that leave target devastated

- **Actionable:** Clear toolkit (horn, face, pockets, chase, leg-up) with escalation pattern
- **Invocable:** Triggered when physical comedy needed, words failing, conventional response expected
